📋 Sección 1

Buenas prácticas generales

Fundamentos esenciales para construir sitios web optimizados

✦

Etiquetas HTML correctas

Utilizar correctamente las distintas etiquetas semánticas como <header>, <main>, <section>, <article>, <nav> y <footer>. Cada etiqueta tiene un propósito específico que ayuda a los motores de búsqueda a entender la estructura y jerarquía del contenido.

📌

Navbar fijo

Mantener un navbar fijo facilita la navegación del usuario permitiendo acceso rápido a secciones importantes sin necesidad de hacer scroll hacia arriba. Esto mejora significativamente la experiencia del usuario (UX), un factor que Google considera para el ranking.

🖼️

Imágenes optimizadas

La optimización de imágenes es crucial para la velocidad de carga del sitio. Incluye:

  • • Compresión: Reducir el tamaño sin perder calidad visible
  • • Formato adecuado: WebP para fotos, SVG para gráficos
  • • Lazy loading: Cargar imágenes solo cuando son necesarias
  • • Dimensiones apropiadas: Evitar redimensionar con CSS
🏗️

Estructura clara del sitio

Una arquitectura de información bien pensada facilita tanto la navegación del usuario como el rastreo por parte de los motores de búsqueda. Debe existir una jerarquía lógica: página principal → categorías → subcategorías → contenido específico. Ninguna página debería estar a más de 3 clics de distancia de la home.

📁

Repositorio ordenado

Mantener un repositorio limpio y organizado en GitHub facilita el mantenimiento, la colaboración y el control de versiones. Utiliza carpetas con nombres descriptivos como /assets, /components, /styles, y mantén un README.md actualizado.

🎨

Imports necesarios en CSS/SASS

Evitar imports innecesarios reduce el tamaño final de los archivos CSS y mejora los tiempos de carga. Cada import adicional representa una petición HTTP extra y bytes adicionales que el usuario debe descargar. Utiliza herramientas de minificación y elimina código no utilizado.

📝

Nombres de archivos claros y descriptivos

Los nombres de archivos deben ser autoexplicativos tanto para desarrolladores como para motores de búsqueda. Por ejemplo: producto-zapatos-deportivos.jpg es mejor que IMG_1234.jpg. Usa guiones (-) en lugar de guiones bajos (_) o espacios.

🚫

Sin código duplicado

El código duplicado aumenta el tamaño de los archivos, dificulta el mantenimiento y puede generar inconsistencias. Utiliza componentes reutilizables, funciones auxiliares y aplica el principio DRY (Don't Repeat Yourself). Esto también facilita actualizaciones futuras.

🎨

Colores consistentes

Mantener una paleta de colores coherente en todo el sitio mejora la identidad de marca y la experiencia del usuario. Define variables CSS para tus colores principales y úsalas consistentemente. Asegúrate de que haya suficiente contraste para cumplir con los estándares de accesibilidad WCAG.

⭐

H1 obligatorio (CRÍTICO)

Regla de oro: Cada página debe tener exactamente UN elemento H1 que describa claramente el contenido principal. El H1 es el título más importante y le indica a Google de qué trata la página.

⚠️ Importante: No uses múltiples H1 en una misma página. La jerarquía debe ser: H1 → H2 → H3 → H4, sin saltar niveles.

🔍 Sección 2

¿Qué es SEO?

Search Engine Optimization - Optimización para motores de búsqueda

Definición

SEO (Search Engine Optimization) es el conjunto de técnicas, estrategias y buenas prácticas diseñadas para mejorar la visibilidad y el posicionamiento de un sitio web en los resultados orgánicos (no pagados) de los motores de búsqueda como Google, Bing y otros.

El objetivo principal es atraer tráfico cualificado y relevante hacia tu sitio web, aumentando así las posibilidades de conversión, ya sea una venta, registro, descarga o cualquier otra acción valiosa para tu negocio.

💡

Concepto clave

SEO no es una sola "cosa" o técnica aislada. Es un ecosistema completo que se divide en distintas áreas especializadas, cada una con sus propias estrategias y mejores prácticas:

📄

SEO On Page

Se enfoca en optimizar todos los elementos internos y visibles de tu sitio web.

  • • Contenido de calidad y relevante
  • • Palabras clave estratégicas
  • • Meta tags y estructura HTML
  • • Optimización de imágenes
🌐

SEO Off Page

Abarca todas las acciones realizadas fuera de tu sitio para mejorar su autoridad y reputación.

  • • Link building (backlinks de calidad)
  • • Presencia en redes sociales
  • • Menciones de marca
  • • Guest posting y colaboraciones
⚙️

SEO Técnico

Se centra en la infraestructura y funcionamiento técnico del sitio web.

  • • Velocidad de carga optimizada
  • • Sitemap XML y robots.txt
  • • Estructura de URLs amigables
  • • HTTPS y certificado SSL
  • • Mobile-friendly y responsive
📍

SEO Local

Optimización específica para negocios con ubicación física o que sirven áreas geográficas específicas.

  • • Google My Business optimizado
  • • Reseñas y valoraciones
  • • Información NAP consistente
  • • Contenido geo-localizado
📄 Sección 3

SEO On Page

Optimización del contenido interno y elementos visibles del sitio

🔑

Palabras clave (Keywords)

Las palabras clave son los términos que los usuarios escriben en los buscadores. Debes:

  • • Investigar: Usar herramientas como Google Keyword Planner, Ahrefs o SEMrush
  • • Ubicar estratégicamente: En títulos, primer párrafo, subtítulos y de forma natural en el contenido
  • • Long-tail keywords: Frases más específicas con menor competencia pero mayor intención de compra
  • • Densidad natural: Evitar keyword stuffing (saturación de palabras clave)
🏷️

Meta tags

Elementos HTML que proporcionan información sobre la página:

Title Tag (Título)

Aparece en la pestaña del navegador y en los resultados de búsqueda. Máximo 60 caracteres.

<title>Guía Completa de SEO 2024 | Tu Marca</title>

Meta Description

Resumen que aparece bajo el título en Google. Máximo 155 caracteres.

<meta name="description" content="Aprende SEO desde cero...">
🖼️

Optimización de imágenes

Las imágenes bien optimizadas mejoran tanto la velocidad como el SEO:

  • • Tamaño reducido: Comprimir sin perder calidad (TinyPNG, ImageOptim)
  • • Nombres descriptivos: "zapatos-deportivos-nike.jpg" vs "IMG001.jpg"
  • • Formato moderno: WebP ofrece mejor compresión que JPG/PNG
  • • Dimensiones correctas: Subir en el tamaño exacto que se mostrará
📝

Atributo ALT en imágenes

El atributo ALT describe el contenido de una imagen y es crucial para:

  • • Accesibilidad: Lectores de pantalla para personas con discapacidad visual
  • • SEO: Google lee el ALT text para entender el contenido de la imagen
  • • Respaldo: Se muestra si la imagen no puede cargarse
<img src="cafe.jpg" alt="Taza de café latte con arte en espuma">
🏗️

HTML semántico

Usar las etiquetas HTML correctas según su propósito semántico ayuda a los motores de búsqueda a entender mejor tu contenido:

<header> Encabezado de la página o sección
<nav> Navegación principal
<main> Contenido principal único de la página
<article> Contenido independiente (blog post, noticia)
<section> Sección temática del contenido
<aside> Contenido relacionado o complementario
<footer> Pie de página con información secundaria
📊

Jerarquía de encabezados

La estructura correcta de encabezados es fundamental para SEO:

H1 - Título principal

Solo UNO por página. Define el tema principal.

H2 - Subtemas principales

Divide el contenido en secciones importantes.

H3 - Subsecciones

Detalles dentro de cada H2.

H4, H5, H6

Para subdivisiones más específicas.

❌ Error común: Saltar de H1 directamente a H3, o usar H2 antes que H1. La jerarquía debe ser siempre secuencial.

🌐 Sección 4

SEO Off Page

Construcción de autoridad y reputación fuera de tu sitio

🔍

Concepto fundamental: Google no solo analiza que el contenido de tu sitio esté bien hecho y optimizado. También evalúa qué tan relevante, confiable y autorizado es tu sitio en internet. El SEO Off Page construye esta reputación externa.

🔗

Backlinks (Enlaces entrantes)

Los backlinks son enlaces desde otros sitios web hacia el tuyo. Son uno de los factores de ranking más importantes:

  • ✓ Calidad sobre cantidad: Un enlace desde un sitio autorizado vale más que 100 de sitios irrelevantes
  • ✓ Relevancia temática: Enlaces desde sitios relacionados con tu industria tienen más peso
  • ✓ Anchor text natural: El texto del enlace debe ser descriptivo y variado
  • ✓ Diversidad: Enlaces desde diferentes dominios y tipos de sitios

⚠️ Advertencia: NUNCA compres backlinks. Google penaliza esta práctica severamente.

📱

Presencia en redes sociales

Aunque las señales sociales no son un factor de ranking directo, una presencia activa en redes sociales:

  • • Aumenta la visibilidad de tu marca y contenido
  • • Genera tráfico referido hacia tu sitio
  • • Facilita que otros descubran y enlacen tu contenido
  • • Construye comunidad y engagement con tu audiencia
📢

Menciones de marca

Cuando otros sitios mencionan tu marca o producto (incluso sin enlazar), Google lo considera una señal de relevancia y autoridad. Esto incluye:

  • • Reseñas en blogs de tu industria
  • • Menciones en medios de comunicación y prensa digital
  • • Comentarios en foros y comunidades especializadas
  • • Referencias en estudios, investigaciones o casos de éxito
🤝

Colaboraciones estratégicas

Trabajar con otros sitios, marcas o creadores de contenido puede amplificar tu alcance:

  • • Co-marketing: Webinars, ebooks o estudios conjuntos
  • • Entrevistas: Aparecer como experto en podcasts o blogs
  • • Partnerships: Alianzas con marcas complementarias
📤

Guest Posting (Publicación como invitado)

Escribir artículos de calidad para otros blogs o publicaciones de tu industria te permite:

  • • Conseguir backlinks desde sitios relevantes y autorizados
  • • Posicionarte como experto en tu campo
  • • Alcanzar nuevas audiencias potencialmente interesadas
  • • Construir relaciones valiosas en tu industria

💡 Tip: Enfócate en calidad, no cantidad. Un artículo excelente en un sitio muy visitado vale mucho más que múltiples artículos mediocres en sitios pequeños.

⚙️ Sección 5

SEO Técnico

Optimización de la infraestructura y funcionamiento del sitio

🔄

Nota importante: El SEO técnico está directamente relacionado con el SEO On Page, pero se enfoca específicamente en cómo los motores de búsqueda pueden acceder, rastrear, interpretar e indexar tu sitio.

⚡

Velocidad de carga (Core Web Vitals)

La velocidad es un factor de ranking crucial. Google mide específicamente:

  • • LCP (Largest Contentful Paint): Tiempo hasta que se carga el contenido principal (debe ser < 2.5s)
  • • FID (First Input Delay): Tiempo de respuesta a la primera interacción (debe ser < 100ms)
  • • CLS (Cumulative Layout Shift): Estabilidad visual durante la carga (debe ser < 0.1)

Cómo mejorar: Comprimir imágenes, minimizar CSS/JS, usar CDN, habilitar caché del navegador, lazy loading.

🖼️

Optimización de imágenes y recursos

Los archivos multimedia mal optimizados son la causa #1 de sitios lentos:

  • • Formatos modernos: WebP (70% más ligero que JPG), AVIF para máxima compresión
  • • Responsive images: Servir diferentes tamaños según el dispositivo
  • • Lazy loading: Cargar imágenes solo cuando el usuario se acerca a ellas
  • • CDN: Servir recursos desde servidores cercanos geográficamente
🏗️

Estructura del sitio y arquitectura

Una arquitectura web bien planificada facilita tanto la navegación del usuario como el rastreo de los bots:

  • • Estructura piramidal: Home → Categorías → Subcategorías → Páginas finales
  • • Regla de 3 clics: Cualquier página debe ser accesible en máximo 3 clics desde home
  • • URLs amigables: /productos/zapatillas-running/ en lugar de /p?id=12345
  • • Enlaces internos: Conectar páginas relacionadas para distribuir autoridad

Ejemplo de buena estructura:

Home /
├── Blog /
│ ├── SEO /
│ │ └── guia-seo-2024/
├── Productos /
│ ├── Zapatillas /
│ │ └── running-profesional/
🤖

Facilitar el trabajo de los motores de búsqueda

Herramientas y archivos que ayudan a los bots a rastrear e indexar tu sitio:

Sitemap XML

Archivo que lista todas las URLs importantes de tu sitio, con metadatos como fecha de modificación y prioridad. Facilita que Google descubra todas tus páginas.

Ubicación: /sitemap.xml

Robots.txt

Archivo que indica a los bots qué páginas pueden o no rastrear. Útil para excluir áreas administrativas o contenido duplicado.

Ubicación: /robots.txt

Datos estructurados (Schema.org)

Código JSON-LD que ayuda a Google a entender el contenido específico: productos, recetas, eventos, reseñas, etc. Permite rich snippets en resultados.

HTTPS y SSL

Certificado de seguridad obligatorio. Google prioriza sitios seguros y los navegadores marcan sitios HTTP como "No seguro".

📱

Mobile-First y Responsive Design

Desde 2019, Google usa el índice "mobile-first", lo que significa que evalúa principalmente la versión móvil de tu sitio:

  • • Diseño responsivo: El sitio debe adaptarse perfectamente a todos los tamaños de pantalla
  • • Botones táctiles: Elementos interactivos de tamaño apropiado (mínimo 48x48px)
  • • Texto legible: Sin necesidad de zoom (mínimo 16px en móvil)
  • • Velocidad móvil: Especialmente crítica en conexiones lentas
🏷️ Sección 6

Meta datos

Información estructurada dentro del <head> del documento HTML

¿Qué son los meta datos?

Los meta datos son fragmentos de información que se colocan en el <head> de tu documento HTML y que no son visibles directamente para los visitantes del sitio, pero sí son leídos por los motores de búsqueda y otros sistemas.

Sirven para:

  • ✓ Definir información adicional del sitio: Título, descripción, autor, idioma, palabras clave, etc.
  • ✓ Proporcionar contexto y estructura: Ayudan a organizar y categorizar el contenido para su mejor interpretación.
  • ✓ Indicar a los buscadores de qué trata la página: Los meta datos son una de las primeras cosas que Google lee al visitar tu página.
  • ✓ Controlar cómo aparece tu sitio: En resultados de búsqueda, redes sociales (Open Graph, Twitter Cards), etc.

Son importantes porque:

  • ★ Facilitan la lectura a los buscadores: Los bots de Google leen los meta datos para entender rápidamente el contenido y relevancia de tu página.
  • ★ Mejoran la indexación: Bien implementados, aceleran el proceso de indexación y ayudan a posicionar mejor en palabras clave específicas.
  • ★ Ayudan a detallar el contenido: Permiten especificar información que no está explícita en el contenido visible (fechas, categorías, autores, etc.)
  • ★ Mejoran el CTR: Un título y descripción atractivos en los resultados de búsqueda aumentan los clics.
💡

Concepto: Indexación

Es el proceso mediante el cual Google (y otros motores de búsqueda) descubren, analizan, almacenan y organizan las páginas web en su base de datos masiva. Cuando tu sitio está indexado, puede aparecer en los resultados de búsqueda.

Fases de la indexación:

  1. 1. Rastreo (Crawling): Los bots visitan y leen tu sitio
  2. 2. Procesamiento: Analizan el contenido, estructura y meta datos
  3. 3. Almacenamiento: Guardan la información en el índice de Google
  4. 4. Ranking: Determinan en qué posición mostrar tu página para cada búsqueda

Meta datos más comunes:

<meta charset="UTF-8">

Define la codificación de caracteres

<meta name="viewport" content="width=device-width">

Configuración para diseño responsive

<meta name="description" content="...">

Descripción que aparece en resultados de búsqueda

<meta name="keywords" content="...">

Palabras clave relacionadas con el contenido

<meta name="robots" content="index, follow">

Instrucciones para los bots de búsqueda

🔑 Sección 7

Meta keywords

Palabras clave específicas para definir el contenido de tu página

Sintaxis básica:

<meta name="keywords" content="palabra1, palabra2, frase clave, palabra3">

Se colocan en el <head> del documento HTML

⚠️

Nota importante sobre meta keywords en 2024:

Google oficialmente ya NO utiliza el meta tag keywords como factor de ranking desde 2009. Sin embargo, algunos otros buscadores menores aún lo consideran. Es mejor enfocarse en el contenido real de la página y en la meta description.

Mejores prácticas (si decides usarlas):

  • • Cantidad: Entre 5 y 10 palabras o frases clave como máximo. Más de eso se considera spam.
  • • Relevancia: Deben estar directamente relacionadas con el contenido de la página específica.
  • • No repetir: Evitar repetir la misma palabra múltiples veces.
  • • Separación: Usar comas para separar cada término.

❌ Evitar palabras genéricas

Palabras demasiado amplias que tienen alta competencia y baja intención específica:

tecnología negocio gratis comida servicios productos

Problema: Son tan vagas que no ayudan a definir tu contenido ni atraen al público correcto.

✅ Usar frases específicas

Frases descriptivas (long-tail keywords) que definen claramente tu contenido y audiencia:

tendencias en tecnología 2024 cursos gratuitos online restaurante vegano Buenos Aires guía SEO para principiantes

Ventaja: Menor competencia, mayor relevancia y mejor tasa de conversión.

⚠️

Regla de oro: No repetir palabras en exceso. Google puede considerar esto como "keyword stuffing" (relleno de palabras clave), una práctica penalizada que puede perjudicar tu ranking.

Ejemplo práctico completo:

Para una página sobre recetas veganas:

<meta name="keywords" content="recetas veganas fáciles, cocina vegana para principiantes, postres veganos sin horno, desayunos veganos rápidos, comida vegana económica">

Para un blog de marketing digital:

<meta name="keywords" content="estrategias de marketing digital, publicidad en redes sociales, email marketing efectivo, contenido viral, SEO para empresas">
📊 Sección 8

Resultados y publicidad

La relación entre SEO orgánico y publicidad pagada (SEM)

💰

La realidad del posicionamiento en Google

Podés tener el mejor sitio web, con SEO impecable, contenido de calidad excepcional, estructura perfecta y todas las buenas prácticas implementadas. Sin embargo, si no invertís en publicidad pagada (Google Ads), no existe garantía absoluta de que aparecerás en las primeras posiciones de búsqueda, especialmente en nichos competitivos.

Esto es especialmente cierto en las primeras etapas de un sitio nuevo, o en industrias con alta competencia.

🌱

SEO Orgánico

  • ✓ Gratis: No pagas por cada clic
  • ✓ Sostenible a largo plazo: Resultados duraderos
  • ✓ Credibilidad: Los usuarios confían más en resultados orgánicos
  • ✗ Lento: Puede tomar 6-12 meses ver resultados significativos
  • ✗ Alta competencia: Difícil destacar en nichos saturados
  • ✗ Incierto: No garantiza primeras posiciones
🚀

SEM (Google Ads)

  • ✓ Resultados inmediatos: Tráfico desde el primer día
  • ✓ Control total: Eliges posición, presupuesto y palabras clave
  • ✓ Medible: ROI claro y rastreable
  • ✗ Costoso: Pagas por cada clic (puede ser muy caro en nichos competitivos)
  • ✗ Temporal: Cuando dejas de pagar, desapareces
  • ✗ Menor confianza: Los usuarios saben que son anuncios

¿Cómo funciona Google Ads?

Google muestra los anuncios pagados en las primeras 3-4 posiciones de los resultados de búsqueda (marcados con "Anuncio" o "Patrocinado"). Solo después aparecen los resultados orgánicos.

Estructura típica de una página de resultados:

AD Anuncio pagado #1
AD Anuncio pagado #2
AD Anuncio pagado #3
Resultado orgánico #1 (SEO)
Resultado orgánico #2 (SEO)
Resultado orgánico #3 (SEO)
✅

Esto NO significa que el SEO no sirva

El SEO sigue siendo extremadamente valioso y Google evalúa permanentemente tu sitio. Un buen SEO te posiciona como autoridad y, con el tiempo, puede llevarte a las primeras posiciones orgánicas sin pagar por publicidad.

  • • Inversión a largo plazo: Los resultados son acumulativos y duraderos
  • • Credibilidad aumentada: Aparecer orgánicamente genera más confianza
  • • Mayor ROI a largo plazo: No pagas por cada visita
  • • Sostenibilidad: No dependes de un presupuesto publicitario continuo

💡 Estrategia recomendada: Combinación SEO + SEM

La estrategia más efectiva suele ser combinar ambos enfoques:

  • 1. Corto plazo: Usar Google Ads para generar tráfico inmediato mientras tu SEO madura
  • 2. Mediano plazo: Trabajar en SEO para construir presencia orgánica sostenible
  • 3. Largo plazo: Reducir inversión en Ads a medida que mejora tu posicionamiento orgánico
⛔ Sección 9

Prácticas penalizadas por Google

Técnicas de "Black Hat SEO" que debes evitar absolutamente

⚠️

Advertencia crítica

Google penaliza severamente las prácticas de manipulación que intentan "engañar" al algoritmo. Las penalizaciones pueden incluir caída drástica en rankings, desindexación parcial o incluso eliminación completa de los resultados de búsqueda. Recuperarse de una penalización puede llevar meses o incluso años.

✗

Contenido robado o duplicado

Copiar contenido de otros sitios web o duplicar el mismo contenido en múltiples páginas.

Penalización: Google prioriza el contenido original y penaliza sitios con contenido duplicado o plagiado.

✗

Keyword Stuffing

Repetir excesivamente palabras clave de manera artificial y poco natural en el contenido.

Ejemplo malo: "Comprar zapatos, zapatos baratos, zapatos online, los mejores zapatos..."

Penalización: Google detecta densidad antinatural de keywords y penaliza el ranking.

✗

Comprar backlinks

Pagar por enlaces desde otros sitios o participar en esquemas de intercambio masivo de enlaces.

Penalización: Google Penguin identifica patrones de enlaces artificiales y aplica penalizaciones severas. Puede resultar en desindexación total.

✗

Contenido engañoso o clickbait

Títulos o descripciones que prometen algo que el contenido no cumple, o información falsa.

Penalización: Afecta negativamente las métricas de usuario (rebote alto, tiempo bajo) y Google reduce la visibilidad.

✗

Velocidad de carga lenta

Sitios que tardan más de 3-4 segundos en cargar, especialmente en dispositivos móviles.

Penalización: Desde 2018, la velocidad es un factor de ranking. Sitios lentos pierden posiciones.

✗

Mala experiencia móvil

Sitios no responsive, texto ilegible, botones muy pequeños o elementos que no funcionan en móvil.

Penalización: Con el índice mobile-first, la versión móvil es prioritaria. Mala experiencia = peor ranking.

✗

Exceso de pop-ups intrusivos

Pop-ups que cubren todo el contenido principal, especialmente en móvil, dificultando el acceso.

Penalización: Google penaliza intersticiales intrusivos que empeoran la experiencia del usuario.

✗

Sitio hackeado o comprometido

Sitios infectados con malware, phishing o que han sido comprometidos por atacantes.

Penalización: Google marca el sitio como "Este sitio puede estar hackeado" y lo elimina de los resultados hasta que se resuelva.

Otras prácticas penalizadas:

  • • Cloaking: Mostrar contenido diferente a usuarios vs. bots de Google
  • • Texto oculto: Texto blanco sobre fondo blanco para incluir keywords invisibles
  • • Doorway pages: Páginas creadas solo para atraer tráfico y redirigir
  • • Link farms: Redes de sitios que se enlazan artificialmente entre sí
  • • Spinning de contenido: Reescribir contenido ligeramente para parecer original
  • • Redirecciones engañosas: Redirigir a los usuarios a páginas inesperadas

✅ En su lugar, enfócate en "White Hat SEO":

  • • Contenido original y valioso que resuelva problemas reales de los usuarios
  • • Enlaces naturales ganados por la calidad de tu contenido
  • • Optimización técnica legítima y centrada en la experiencia del usuario
  • • Transparencia y honestidad en toda tu estrategia de marketing
📍 Sección 10

SEO Local

Optimización para negocios con ubicación física o servicios locales

📍

¿Qué es el SEO Local?

El SEO Local es la práctica de optimizar tu presencia online para atraer más clientes desde búsquedas locales relevantes. Es fundamental para negocios físicos (restaurantes, tiendas, oficinas) o servicios que operan en áreas geográficas específicas (fontaneros, abogados locales, etc.).

🏢

Google My Business (GMB) / Google Business Profile

Es la herramienta MÁS IMPORTANTE para SEO Local. Es gratuita y aparece en:

  • • Google Maps: Cuando alguien busca negocios cerca
  • • Panel de conocimiento: Cuadro a la derecha en resultados de búsqueda
  • • Local Pack: Los 3 resultados destacados con mapa

Información que debes completar en GMB:

  • ✓ Nombre del negocio exacto
  • ✓ Dirección completa y precisa
  • ✓ Teléfono de contacto
  • ✓ Horarios de atención (actualízalos en feriados)
  • ✓ Categoría del negocio (muy importante)
  • ✓ Sitio web
  • ✓ Descripción del negocio (750 caracteres)
  • ✓ Fotos de alta calidad (interior, exterior, productos)
  • ✓ Atributos (ej: "Acceso para sillas de ruedas")
📋

Concepto NAP (Name, Address, Phone)

NAP es un acrónimo fundamental en SEO Local que representa la información básica de contacto de tu negocio:

N

Name (Nombre)

El nombre legal de tu negocio, exactamente como está registrado

A

Address (Dirección)

Tu dirección física completa: calle, número, ciudad, código postal, provincia/estado

P

Phone (Teléfono)

Número de teléfono local con código de área

⚠️ REGLA DE ORO: Consistencia absoluta

Tu información NAP debe ser EXACTAMENTE IGUAL en todos los sitios donde aparezca:

  • • Tu sitio web (footer, página de contacto)
  • • Google My Business
  • • Redes sociales (Facebook, Instagram, LinkedIn)
  • • Directorios locales y páginas amarillas
  • • Perfiles en sitios de reseñas (Yelp, TripAdvisor)
  • • Mapas y apps de navegación

Ejemplo de error: Si en un sitio dices "Av. Corrientes 1234" y en otro "Avenida Corrientes 1234", Google puede confundirse y perjudicar tu ranking local.

⭐

Reseñas y valoraciones

Las reseñas de clientes son uno de los factores más importantes para ranking local:

  • • Cantidad: Más reseñas = más confianza y mejor posicionamiento
  • • Calidad: Valoración promedio alta (idealmente 4.5+ estrellas)
  • • Frecuencia: Reseñas recientes tienen más peso que antiguas
  • • Respuestas: Responder a todas las reseñas (positivas y negativas) muestra compromiso

💡 Tip: Pide reseñas a clientes satisfechos. Puedes enviar un link directo que facilite dejar la reseña en Google.

✨

Otras acciones importantes para SEO Local

Publicar regularmente en Google

Usa las "Publicaciones" de GMB para compartir ofertas, eventos, noticias o contenido relevante. Mantiene tu perfil activo.

Contenido geo-localizado

Incluye en tu sitio web contenido específico sobre tu ubicación: "Restaurante en Palermo, Buenos Aires", páginas de localización si tienes múltiples sucursales.

Directorios y listados locales

Registra tu negocio en directorios locales relevantes, cámaras de comercio, asociaciones de tu industria.

Citas locales (Local Citations)

Menciones de tu NAP en otros sitios web, incluso sin enlace. Validan tu ubicación y existencia.

Enlaces desde sitios locales

Backlinks desde periódicos locales, blogs de tu ciudad, organizaciones comunitarias, etc.

🌐 Sección 11

Cómo funciona una página web

Fundamentos: Servidores, Dominios y Hosting

💡

Antes de profundizar en SEO, es importante entender los conceptos básicos de cómo funciona una página web y los elementos técnicos necesarios para que exista en internet.

🖥️

¿Qué es un servidor?

Un servidor es una computadora potente y especializada que está encendida 24/7 y conectada permanentemente a internet. Su función principal es:

  • • Almacenar datos: Todos los archivos de tu sitio web (HTML, CSS, JavaScript, imágenes, videos, bases de datos)
  • • Enviar información: Cuando alguien visita tu sitio, el servidor envía los archivos necesarios al navegador del visitante
  • • Responder solicitudes: Procesa peticiones (consultas a bases de datos, formularios, etc.) y devuelve respuestas
  • • Garantizar disponibilidad: Asegura que tu sitio esté accesible en todo momento

Tipos de servidores:

Compartido: Múltiples sitios en un mismo servidor (económico, para sitios pequeños)
VPS: Servidor virtual privado con recursos dedicados (balance precio-rendimiento)
Dedicado: Servidor completo solo para tu sitio (máximo rendimiento, costoso)
Cloud: Red de servidores interconectados (escalable, confiable)

Ejemplos de proveedores:

Microsoft Azure Amazon Web Services (AWS) Google Cloud DigitalOcean Hostinger
🌍

¿Qué es un dominio?

Un dominio es la dirección única y legible que identifica tu sitio web en internet. Es lo que los usuarios escriben en el navegador para acceder a tu sitio.

Ejemplo de dominio completo:

blog . misitio . com

Subdominio

Opcional, para secciones específicas

Dominio

Tu nombre único

TLD

Top-Level Domain (extensión)

Extensiones TLD comunes:

.com - Comercial (el más popular) | .org - Organizaciones | .net - Redes | .edu - Educativo | .ar / .es / .mx - Por país

Sistema DNS (Domain Name System):

El DNS es como la "agenda telefónica" de internet. Traduce nombres de dominio legibles (ejemplo.com) a direcciones IP numéricas (192.168.1.1) que las computadoras entienden.

Costo de dominios:

  • • Gratuitos: Subdominios como misitio.wordpress.com, misitio.github.io
  • • De pago: Dominio propio desde $10-15 USD/año (.com típico)
  • • Premium: Dominios cortos o muy demandados pueden costar miles
📝

Registro de dominios

Para obtener un dominio, debes registrarlo a través de un registrador de dominios acreditado. El registro típicamente se renueva anualmente.

Registradores populares:

Hostinger GoDaddy Namecheap Google Domains Domain.com Cloudflare

💡 Tips para elegir un buen dominio:

  • ✓ Corto y fácil de recordar
  • ✓ Fácil de escribir (sin guiones ni números complicados)
  • ✓ Relacionado con tu marca o negocio
  • ✓ Preferir .com si está disponible (más confiable)
  • ✓ Verificar que no esté muy similar a marcas existentes

🔄 ¿Cómo se conectan servidor y dominio?

Paso 1: Usuario escribe el dominio

El usuario ingresa "www.ejemplo.com" en su navegador

↓

Paso 2: Consulta DNS

El DNS traduce "ejemplo.com" a la IP del servidor (ej: 192.168.1.100)

↓

Paso 3: Conexión al servidor

El navegador se conecta al servidor usando la dirección IP

↓

Paso 4: Servidor envía archivos

El servidor envía HTML, CSS, JS e imágenes al navegador del usuario

↓

Paso 5: Renderizado

El navegador interpreta los archivos y muestra la página web al usuario

Todo este proceso ocurre en milisegundos ⚡
